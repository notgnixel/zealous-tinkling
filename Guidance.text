Guidance to update total quiz count:
- Navigate to "Edit theme" on Shopify portal.
- Navigate to "Hair Quiz" page on the website/theme.
- Under "Template" navigate to "custom liquid" (custom liquid is under a section under Template).
- Click anywhere in the custom liquid and perform the search function (control + f/ Mac command + f). 
- Search for "countlabel".
- Update the number here.
- Save theme.

Guidance to update product photos:
- Go to the files folder and use the shopify search key to find the file you need.
- Without clickig on the file, slide mouse to the furthest left point on the file background.
- You will see an icon that says "copy link" when the mouse is on it.
- Click that icon.
- Continue first 4 steps of previous guidance.
- Search for "photo =".
- Update link to the matching product label in the above text.
- Edit what is inside single quotes ('https://cdn.shopify.com/s/files/1/0741/0797/8022/files/Win-4.png?v=1773358086').
- Save theme.
